## 🎯 Architecture & Design Philosophy
This portfolio is engineered according to strict enterprise specifications:
- **10-Second Recruiter Test:** Immediately communicates identity, core technical direction (Java + Spring Boot + Full Stack), verified credentials, and flagship systems.
- **Zero Fabrication Rule:** No artificial corporate positions, no unverified stats, and no generic skill percentage bars (e.g., "Java 98%"). All technical claims are grounded in verified academic excellence and public GitHub repositories.
- **Design Persona:** "Modern SaaS + Engineering Dashboard" (inspired by Linear, Vercel, and Stripe) featuring a primary obsidian/navy dark theme and a polished light theme.

## ⚡ Flagship Projects Featured

1. **Digital Customer Onboarding Platform** *(Main Flagship)*
   - **Role:** Frontend Lead (Team of 4)
   - **Stack:** React 19, Vite, Tailwind CSS v3, React Router DOM v7, React Context API, Axios, JWT.
   - **Key Highlights:** 8-stage banking onboarding state machine (KYC, document uploads, review & consent, banking analytics dashboard) with session recovery.

2. **Online Examination & Assessment System**
   - **Role:** Backend & Database Developer
   - **Stack:** Core Java, Java Servlets, JDBC, MySQL, JUnit.
   - **Key Highlights:** Concurrent examinee sessions, automated synchronized timers, transactional JDBC with ACID guarantees, and zero SQL injection via parameterized queries.

3. **Store Rating Platform**
   - **Role:** Full Stack Developer
   - **Stack:** React.js, REST APIs, MySQL, JWT, RBAC.
   - **Key Highlights:** 3-tier Role-Based Access Control differentiating Normal Users, Store Owners, and System Administrators.

4. **Mini ERP + CRM Operations Portal**
   - **Role:** Full Stack Developer
   - **Stack:** React 19, Node.js 22, Express 5, TypeScript, Prisma ORM, MySQL/Postgres, Zod, JWT.
   - **Key Highlights:** Cross-departmental operational flow (Sales, Warehouse, Accounts, Admin) with Zod runtime validation.

5. **Industrial Manufacturing & Supply ERP**
   - **Role:** Systems & Concurrency Engineer
   - **Stack:** PostgreSQL, Express, React, TypeScript, Docker.
   - **Key Highlights:** Pessimistic database row-level locking (`SELECT FOR UPDATE`), inventory reservation safeguards, and CHECK constraints preventing negative stock over-allocation.

## 💻 Local Development Setup

### Prerequisites
- **Node.js:** v18.0.0 or higher (v22 LTS recommended)
- **Git**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/manesuraj14/suraj-portfolio.git
   cd suraj-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment variables:**
   ```bash
   cp .env.example .env
   ```

4. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

## 🌐 Deployment to Vercel

### Option 1: Vercel Dashboard (Recommended)
1. Push code to GitHub: `git push -u origin master`
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New..."** ➔ **"Project"**.
4. Select `manesuraj14/suraj-portfolio`.
5. Vercel will automatically detect **Vite** as the framework preset:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
6. Click **Deploy**. Your portfolio will be live in under 1 minute with automatic SSL!

### Option 2: Vercel CLI
```bash
npm i -g vercel
vercel login
vercel --prod
```
